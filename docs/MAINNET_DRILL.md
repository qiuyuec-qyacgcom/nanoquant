# 主网小额演练手册

> 状态：**尚未执行**。所有成交验证目前都在币安测试网完成（见 `TASKS.md` #49–#52）。
> 本文是主网首跑的检查单与判据，不是"已经验证过"的结论。

## 0. 为什么必须单独做一次

测试网与主网的差异不在"能不能下单"，而在这些细节：

| 项 | 测试网 | 主网 |
|---|---|---|
| 最小名义额 | 统一偏大（BTC 约 50U） | 每个标的不同（BTC 100U / ETH 20U / 多数山寨 5U） |
| 保护单接口 | `algoOrder` 已支持 | 同一套，但参数校验更严（触发价必须满足 tick/方向） |
| 撮合深度 | 稀疏，滑点不可信 | 有深度，滑点可测 |
| 资金费 | 有，但费率不具代表性 | 每 8h 真实结算 |
| 持仓模式 | 默认单向 | 账户级设置，可能被其他工具改成双向 |

## 1. 前置条件（缺一不可）

- [ ] 主网 API Key/Secret 已保存（「参数配置 → 数据源 → 实盘」），且**只开合约交易权限，关闭提现**
- [ ] 主网钱包余额 ≥ 30 USDT（覆盖最小名义额 + 缓冲）
- [ ] 标的池只保留 1 个标的（建议 `ETHUSDT`），并把杠杆降到 **3x**、单笔风险降到 **1%**
- [ ] 引擎处于 **停止** 状态；系统诊断 9 项全绿
- [ ] `exec_mode=off`（Rust sidecar 不参与首跑，减少变量）
- [ ] 手动记录时间与账户余额，演练结束后对账

## 2. 只读预检

```bash
python scripts/mainnet_preflight.py --yes
```

它会用实盘凭证连主网，检查：连通性 / 账户可读 / 持仓模式 / 遗留挂单 / 每个标的的最小名义额与所需保证金。
**只读，不下单**。任何一项 FAIL 都不要继续。

## 3. 演练 A：最小名义额开平（约 1–2 分钟）

1. 「参数配置 → 交易环境」切到实盘，输入确认短语 `LIVE`；
2. 打开「开仓检查」，确认目标标的的「所需保证金」小于余额的 30%；
3. 启动引擎，等一轮扫描（默认 5s）；也可在总览点「立即扫描」；
4. 若开仓失败，按信号审计的拒绝原因处理（常见：最小名义额、点差闸门、AI 否决）；
5. 开仓成功后立刻检查：
   - 总览「当前持仓」数量与交易所一致；
   - 「交易所保护单」有 **2 条**（STOP_MARKET + TAKE_PROFIT_MARKET），触发价方向正确；
   - `/engine/status` 的 `stats.execution.latency_p50` 有值。
6. 手动平仓（总览持仓行「平仓」），确认：
   - 本地 `status=closed`、`qty` 归零；
   - `openOrders` 与 `openAlgoOrders` 均为空（不会有裸奔保护单）；
   - 新增 1 条 `TradeRecord`，`exit_reason=manual`。

**判据**：数量一致、保护单 2 条、平仓后无残留挂单。任一不符 → 立刻停止并切回模拟盘。

## 4. 演练 B：部分止盈（约 5–20 分钟，取决于行情）

主网不可能"按需"制造 1R 涨幅，用临时参数让它在小幅盈利时触发：

1. 停止引擎 → 「参数配置 → 策略 → 部分止盈」把 `partial_tp_at_r` 临时改为 **0.1**（即 0.1R）；
2. 启动引擎，等待开仓并在小幅盈利时触发部分止盈；
3. 触发后检查：
   - 持仓数量减半、`status=open`，页面显示「已部分止盈」；
   - 剩余仓位的止损价被上移到**开仓价**（保本）；
   - 新增 1 条 `TradeRecord`，`exit_reason=partial_tp`，数量=半仓；
   - 保护单仍存在（部分平仓**不应**撤保护单）；
4. 手动全平，确认保护单清空、成交记录共 2 笔；
5. **把 `partial_tp_at_r` 改回 1.0**，并检查配置已落库。

**判据**：数量减半 + 止损上移 + 保护单仍在 + 两笔记账。特别注意第 3 步与 #50 的测试网结论一致。

## 5. 演练 C：资金费与统计口径

- 若持仓跨过 UTC 00:00/08:00/16:00，记录 `income` 接口里的 `FUNDING_FEE`；
- 与回测的 `funding_bps_8h` 假设（默认 1bp/8h）对比，偏差大就把实测值写进回测参数；
- 运行 `python scripts/reconcile.py --mode live`（需 ≥10 笔成交），按输出的 `suggested_slippage_bps` 调整回测滑点。

## 6. 成本与停止条件

- 预算上限：**≤ 2 USDT**（手续费 + 点差 + 滑点 + 可能的一次止损）；
- 立即停止（切回模拟盘、清空挂单）的条件：
  - 本地数量与交易所不一致；
  - 出现裸奔仓位（无保护单）；
  - 重复下单 / 平仓后仍有残留挂单；
  - 连续两次下单被拒且原因不明。

## 7. 回滚

1. 总览「引擎控制」→ 停止；
2. 「参数配置 → 交易环境」切回**模拟盘**（无需短语）；
3. 交易所侧确认无挂单、无持仓；
4. 把 `partial_tp_at_r`、`default_leverage`、`risk_per_trade_pct` 恢复默认（1.0 / 20 / 10）；
5. 记录演练结果到 `TASKS.md`，附余额变化与成交截图。
