## 〇、术语：两套「策略」不要混

系统里有两个都叫「策略」的东西，作用完全不同，混起来会白调半天参数：

| | `StrategySettings`（本文件的策略） | `StrategyProfile` |
|---|---|---|
| 界面上叫 | **参数配置 → 策略** | **AI 策略** |
| 存哪 | `app_settings` 的 `strategy` 分组 | `strategy_profiles` 表（多条） |
| 是什么 | 引擎**真正执行**的硬参数：模式、周期、杠杆区间、止损止盈、准入闸门 | 交给 AI 的**文本判断指令**（一段中文正文） |
| 谁执行 | 代码：`build_features` → `score_signal` → `detect_exit` | 模型：读正文后自行判断是否开仓 |
| 能不能改杠杆/止损 | **能**（`leverage_min/max`、`sl_atr_mult`…） | **不能**（风控铁律不可被文本覆盖） |
| 什么时候生效 | 每轮扫描 | AI 决策时（命中适用标的） |

一句话：**`StrategySettings` 决定机器怎么做，`StrategyProfile` 建议模型怎么想**。调「快慢/杠杆/止损」去参数配置；调「AI 的分析口吻与判断规则」去 AI 策略。

## 一、策略哲学

**短线赚钱的不是「预测更准」，而是「低杠杆 + 拿得住 + 只在少数确定性机会出手」。**

五条证据链（详见 EVIDENCE.md）：

1. 本系统多轮回测：5m/15m 高频趋势跟随样本外全负，止损率 66%；
2. 熬鹰 111 笔真实持仓：3x 杠杆胜率 82%、PF 6.79；5x+ 高杠杆回撤 62.9%；
3. 熬鹰持仓 >1 天胜率 69%、<1h 胜率 33%——利润来自「拿得住」；
4. 成本敏感性：费率 5bp→2bp 期望改善 35%——成本在短线是决定性的；
5. 4h 均值回归是唯一出现过「样本外不亏」的配置（ETH/SOL 微正）。

```
                                                  │

```

## 三、信号层：均值回归

`mode = meanrev` 时生效。核心判断：**价格偏离布林中轨足够远，赌它回归**。

| 组件 | 规则 | 参数 |
|---|---|---|
| 偏离度量 | 布林标准分 `z = (close − 中轨) / σ` | `mr_window`（默认 20 根） |
| 触发 | `|z| ≥ mr_z_entry` 时反向入场（涨过头做空、跌过头做多） | `mr_z_entry`（默认 2.0，常用 1.5） |
| 顺大逆小 | 强趋势里禁止逆势回归（EMA 间距超阈值即放弃） | `mr_block_in_trend`、`mr_trend_gap_pct` |
| 动能确认 | 放量突破极值时打折（可选，开更稳、关更多信号） | `mr_exhaustion_confirm` |
| 盈亏比 | 回归目标回中轨，R:R 底线比趋势模式低 | `mr_min_risk_reward`（默认 0.8） |

**为什么用 meanrev 不用 trend**：趋势因子在 5m/15m 的 IC 稳定为负（-0.04~-0.07），
即「价格越强未来越跌」，趋势跟随在结构上是做反了（详见 EVIDENCE.md 三、四节）。

## 四、仓位层：策略杠杆区间

`StrategySettings.leverage_min / leverage_max` 是**策略自己的目标杠杆区间**，与风控分组的
全局上下限（`RiskSettings.default_leverage / max_leverage`）**解耦**：

- 策略下限可低于全局下限（如策略 8、全局 20 → 按 8 走）；
- 策略上限仍被全局硬上限与交易所上限压回；
- 只约束**策略自主开仓**；跟单开仓走 `follow_leverage`，不受影响；
- 0 表示沿用对应方向的全局值，可一键回退。

> ⚠️ 数据结论与「高杠杆快翻倍」是冲突的：真实数据里 **3x 是甜点（PF 6.79）**，
> 5x+ 是亏损源（回撤 62.9%）。若把策略杠杆设到 8-30x，回撤会显著放大，
> 此时**风控层（回撤熔断、连亏暂停）比任何时刻都重要**，单笔风险必须压到下限。

## 五、出场层：拿得住

| 规则 | 设计 | 参数 |
|---|---|---|
| 不做快速止盈 | 关闭时间阶梯止盈（0.8% 落袋是「赢小输大」的根源） | `roi_table = []` |
| 不做部分止盈 | 要么全仓拿住，要么不做（可选） | `partial_tp_at_r = 0` |
| 移动止损延后启动 | 浮盈先走到 N 倍风险才接管，避免开仓即被噪声扫掉 | `trailing_arm_r`（默认 1.0-1.5） |
| 移动止损回撤 | 从峰值回撤该比例离场；太窄会频繁扫单 | `trailing_pct`（0.8 太窄，1.5-2.0 更稳） |
| 时间止损 | 拿得住，但趋势衰减要释放资金 | `max_hold_minutes`、`max_hold_minutes_chop` |

**历史教训**：模拟盘 24 笔 `trailing_stop` 全亏，根因是 `trailing_pct=0.8%` 小于 ATR
止损距离、且从开仓即 arm。修复即 `trailing_arm_r`（详见 EVIDENCE.md 七节）。

## 六、风控层（兜底，不可谈判）

| 项 | 作用 | 关键参数 |
|---|---|---|
| 全局回撤熔断 | 权益从峰值回撤超限即停开新仓 | `max_drawdown_pct` |
| 日亏限额 | 单日亏损超限即停 | `daily_loss_limit_pct` |
| 连亏暂停 | 连亏 N 笔进入冷静期 | `consecutive_loss_limit` |
| 止损熔断 | 窗口内多次止损 → 全局暂停（0=关） | `stoploss_guard_count` |
| 总敞口 | 名义额/权益上限（**满仓高杠杆必须放宽**） | `max_exposure_pct` |
| 相关性组敞口 | 山寨多仓本质是加杠杆（0=关） | `category_exposure_limit_pct` |
| 强平价监控 | 标记价逼近强平价时告警 | `liquidation_warn_pct` |

## 七、成本层：下单类型

| 类型 | 费率 | 适用 |
|---|---|---|
| `market`（taker） | 0.05% | **需要快速成交**：山寨暴涨暴跌、追行情、快速翻倍 |
| `limit_post_only`（maker） | 0.02% | 低频、不急于成交、省成本（如 4h 波段） |

费率每降 1bp，期望改善约 0.04R（见 EVIDENCE.md 五节）。但**快速行情里 maker 单会挂不上**，
错过一次行情的代价远大于省下的 0.03%。市价单有 `max_slippage_pct` + 盘口二次确认兜底。

## 九、可选策略：熬鹰事件镜像

独立于主策略的可选方案：**跟随币安带单员熬鹰的 2-3x 杠杆重仓操作**。

| 环节 | 规则 |
|---|---|
| 入场 | 仅 2x ≤ 杠杆 ≤ 3x、名义额 ≥ 50 万 U、滑点闸 1.5% + 回归补仓、单笔 ≤ 资金 10% |
| 出场 | 他平仓无条件跟平；浮盈回撤 80% 主动平；持仓 >3 天强平；过滤 <1h 超短线 |
| 风控 | 回撤 20% 熔断、日亏 5%、连亏 4 笔、杠杆上限 3x |

回测（111 笔真实持仓）：只跟 2-3x → 胜率 70.7%、PF 6.79、回撤 13.0%；
再加「持仓 >1h」过滤 → 胜率 77.1%、PF 7.67、回撤 12.8%。
代价是砍掉 20x 的 +120 万暴利（总盈亏 216 万 → 117 万）。

> 定位：本质是「跟随 + 风控对冲」，不创造 alpha。熬鹰已减少公开喊单，历史业绩不代表未来。
> 详细分析见 EVIDENCE.md 八节。

## 十、已知陷阱（踩过的坑）

1. **敞口限制会静默拦满仓**：`max_exposure_pct=2000%` 时，10u 满仓 30x（3000% 敞口）
   会在下单时被拦，表现为「看着满仓、实际下不进去」。满仓高杠杆必须放宽到 ≥3000%。
2. **量比闸门会拦低量能时段**：`volume_ratio_min=0.8` 在凌晨低量时段会让所有标的「量能不足」。
3. **波动率上限会拦山寨**：`atr_pct_max=4%` 会把 ATR 10%+ 的暴涨暴跌山寨全部拦掉。
4. **移动止损从开仓即 arm**：必须配 `trailing_arm_r`，否则噪声扫单（24 笔全亏的教训）。
5. **手动开仓需对账**：手动开的仓走对账补录，止损止盈来自保护单接口、杠杆要用
   `名义额 / positionInitialMargin` 反推（接口不返回 leverage 字段）。
6. **日亏基准要跟着资金重置**：重置模拟盘资金后，`day_start_equity` / `equity_peak`
   不跟着重置会误判「日内亏损 -99%」触发熔断。

## 十一、诚实标注：哪些已验证、哪些是假设

| 部分 | 状态 |
|---|---|
| 低杠杆（2-3x）优于高杠杆 | ✅ 111 笔真实数据验证（PF 6.79 vs 2.12） |
| 拿得住（>1 天）优于快进快出 | ✅ 111 笔真实数据验证（69% vs 33% 胜率） |
| 成本：maker 省费率 | ✅ 回测验证（-30%→-19%） |
| OHLCV 5m/15m 高频趋势跟随负期望 | ✅ 6 轮 walk-forward 验证 |
| 4h 均值回归样本外不亏 | ✅ 方向成立（ETH/SOL 微正），但 alpha 很薄 |
| **8-30x 高杠杆能快速翻倍** | ❌ **未验证，且与数据相反**：高杠杆是亏损源，大概率快速归零 |

**核心诚实判断**：这套系统值钱的不是「信号能赚钱」（尚未证明），而是
**执行链路、风控、可验证性**——这三样比一个「回测很好看」的策略稀缺得多。
