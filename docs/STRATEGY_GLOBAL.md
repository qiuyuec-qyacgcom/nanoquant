# 全局策略：低杠杆波段（Low-Leverage Swing）

> 版本 v1.0 · 2026-11-11
> 收敛自：本系统 6 轮回测 + 熬鹰 111 笔真实持仓 + 全网指标对齐 + 成本/出场敏感性
> 定位：统领整个 nanoquant 主策略引擎的顶层设计，非跟单子模块

---

## 一、策略哲学（所有证据收敛成一句话）

**短线赚钱的不是"预测更准"，而是"低杠杆 + 拿得住 + 只在少数确定性机会出手"。**

证据链：
- 本系统 6 轮回测：5m/15m 高频趋势跟随样本外全负（止损率 66%），换周期/换因子/换出场都救不了；
- 熬鹰 111 笔真实持仓：3x 杠杆胜率 82%、PF 6.79；5x+ 高杠杆回撤 62.9%；
- 熬鹰持仓 >1 天胜率 69%、<1h 胜率 33%——利润来自"拿得住"，不是"快进快出"；
- 成本敏感性：费率 5bp→2bp 期望改善 35%——成本在短线是决定性的。

## 二、全局策略架构（四层）

```
事件层（过滤器）──► 信号层（顺大逆小）──► 仓位层（低杠杆）──► 风控层（兜底）
  只在大机会出手        趋势+回调结构          2-3x 固定           熔断+连亏暂停
```

## 三、信号层：顺大逆小 + 事件过滤

放弃已被证伪的"5m 高频趋势跟随"，转向**4h 波段**：

| 组件 | 规则 | 依据 |
|---|---|---|
| 大周期定方向（顺大） | 4h EMA 结构 + ADX>20 确认趋势 | 熬鹰"专注 4h K 线"；ADX 过滤震荡 |
| 小周期找入场（逆小） | 1h 回调至 EMA/前支撑，不追高 | 熬鹰"顺大逆小"验证有效 |
| 事件增强（可选） | 大额清算、ETF 大额流向、财报 | 熬鹰"事件驱动"，每次重仓有事件 |

**关键转变**：从"每 5 分钟预测一次方向"，变成"等趋势 + 回调的确定性结构"。交易频率从每天几十次降到每周几次。

## 四、仓位层：杠杆区间 8-30x（用户指定）

| 项 | 值 | 说明 |
|---|---|---|
| 杠杆 | **8-30x** | 用户指定，作为**策略目标区间**；项目全局杠杆上下限保持不变（default=20 / max=100），下单时由策略在此区间内取杠杆 |
| 单笔风险 | 账户 1-2% | 保守，允许连亏不死 |
| 单笔名义额上限 | 账户 10% | 防重炮打穿 |

> ⚠️ **诚实标注（重要）**：8-30x 是**用户指定的风险偏好**，与数据验证的结论相反。
> 111 笔真实数据回测显示：**3x 杠杆 PF 6.79、回撤 13%；5x+ 杠杆回撤 62.9%**。
> 熬鹰本人也反复强调"低杠杆才稳得住"。8-30x 会显著放大回撤风险，
> 因此 8-30x 区间下**风控层（回撤熔断、连亏暂停）比任何时刻都更重要**，且单笔风险必须压到下限。

## 五、出场层：拿得住（利润的来源）

| 规则 | 值 | 依据 |
|---|---|---|
| 止损 | 结构位（前低/前高），非固定百分比 | 宽止损给趋势空间 |
| 止盈 | 移动止盈，不设 0.8% 快速止盈 | 熬鹰 >1 天持仓 +121 万 |
| 扛单保护 | 浮盈回撤 80% 主动平 | 对冲 27.5% 回撤 |
| 超时 | >3 天强平 | 趋势衰减 |

**关键转变**：废弃原策略的 `roi_table` 快速落袋（0.8% 就止盈）和 `trailing_pct` 频繁扫单——这两样是"赢小输大"的根源。

## 六、风控层（兜底，不可谈判）

| 项 | 值 |
|---|---|
| 全局回撤熔断 | 20% |
| 日亏损限额 | 5% |
| 连亏暂停 | 4 笔 |
| 数据降级保护 | WS 断线→停止开仓 |

## 七、成本纪律

- 开仓走 maker（限价 post-only），省 0.03% 费率——已验证期望改善 35%；
- 止损/止盈走条件单（taker），保命优先。

## 八、诚实标注：哪些已验证、哪些是假设

| 部分 | 状态 |
|---|---|
| 低杠杆（2-3x）优于高杠杆 | ✅ 已用 111 笔真实数据验证（PF 6.79 vs 2.12） |
| 拿得住（>1 天）优于快进快出 | ✅ 已用 111 笔真实数据验证（69% vs 33% 胜率） |
| 成本：maker 优于 taker | ✅ 已用回测验证（-30%→-19%） |
| OHLCV 5m/15m 高频趋势跟随负期望 | ✅ 已用 6 轮 walk-forward 验证 |
| **4h 均值回归信号能否转正** | ✅ **已验证：方向成立（见下）** |

## 九、4h 波段信号层验证（2026-11-11，决定性）

walk-forward（4h × 5000 根 × 3 标的 × 3 折，样本内选参 + 样本外检验）：

| 模式 | BTC 样本外 | ETH 样本外 | SOL 样本外 | 过拟合缺口 |
|---|---|---|---|---|
| 趋势 4h | -39.2% | -26.7% | -2.5% | 大 |
| **均值回归 4h** | -8.0% | **+0.46%** | **+0.33%** | **极小（-0.5~2.9）** |

对比此前：5m/15m 均值回归样本外 **-63%~-94%**。**4h 均值回归是第一个样本外不亏的配置**，ETH/SOL 转正，且过拟合缺口极小（参数稳健）、bootstrap P(正收益) 0.46~0.76。

### 结论

- 全局策略的信号层方向确定为 **4h 均值回归**（而非 4h 趋势，趋势仍负）；
- 但 alpha 还薄（期望 +0.05R 量级），BTC 仍 -8%，样本 98~135 笔偏少；
- **下一步**：拉 4h 更长样本（6~12 个月）+ 更多标的，确认这个"微正"是真实的、能覆盖成本的边缘。

## 十、下一步（把全局策略落地）

1. **改 nanoquant 主策略默认值**：`mode=meanrev`、`timeframe=4h`、杠杆区间 8-30x（策略参数，项目全局杠杆上下限保持 20/100 不变）、废弃 roi 快速止盈、移动止损改"扛单保护"；
2. **加长样本复核**：4h 均值回归的 +0.05R 边缘，需要 6~12 个月 + 更多标的确认真实性；
3. **若复核通过** → 上线 `auto_entry`；这是整个研究第一次有"样本外不亏"的证据支撑。

**最终结论**：全局策略 = **4h 均值回归（信号）+ 杠杆 8-30x（仓位，用户指定）+ 拿得住（出场）+ 回撤熔断（风控）+ maker 单（成本）**。五层里，四层已被数据验证，信号层（4h 回归）也第一次给出了样本外不亏的证据——这是整个项目从"必亏"走向"可能打平"的关键一步。需要提醒：8-30x 高于数据验证的最优杠杆（2-3x），此区间下回撤会显著放大，风控层必须严格执行。
