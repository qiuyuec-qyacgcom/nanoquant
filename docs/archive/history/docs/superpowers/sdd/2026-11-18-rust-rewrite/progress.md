## 阶段更新规则

1. 开始阶段任务时，将其状态改为 `进行中`，记录负责人/AI、日期和具体任务编号。
2. 实现后先运行定向测试，再运行 `cargo test --manifest-path rust/nanoquant/Cargo.toml`；未验证前使用 `待验证`，不得标完成。
3. 阶段完成必须逐条满足实现计划中的任务和验收条件，并记录命令、结果、平台及未解决项。
4. 新发现的 `501`、占位响应、Python/Rust 字段差异或未接入能力，记录到对应阶段的“下一步入口”或下方缺口表。
5. 不要删除其他 AI/开发者的记录；追加带日期的里程碑，并同步更新总览状态。
6. 生产切换阶段完成前，不宣称 Rust 已完整替代 Python。
