# 执行内核 exec-core 实现计划（一期）

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 用全新的默认执行内核 `rust/exec-core`（签名校验 + 七段延迟指标聚合 + 长连接）替代可选组件 `rust/exec-service`（sidecar），主服务下单路径七段埋点异步上报，面板显示 p50/p95/p99/max，一期强依赖（握手失败拒绝启动交易）。

**架构：** 独立进程 exec-core（UDS+TCP 双监听，JSON Lines 协议 v1.0）；主服务新增 `exec_client.rs` 长连接客户端（握手/心跳 5s/指数退避重连），统一替换现有三份 JSON Lines 客户端；下单路径 `SegmentTimer` 计时 → tokio mpsc 有界队列（8192，满则丢弃计数）→ 攒批（64 条/批或 200ms）`metrics_ingest` 上报；面板经 `GET /system/exec-core` 读 `metrics_query` 分位数。二期 op（order_open/order_close/protection_place）仅预留协议号。

**技术栈：** Rust（tokio 1 / serde / serde_json / base64 / hmac / sha2 / ed25519-dalek 2）、Vue3 前端、PowerShell/Bash 部署脚本。规格：`docs/superpowers/specs/2026-11-23-exec-core-design.md`（已与用户逐节确认，本计划不得偏离）。

**环境约束：** 所有工具与依赖都在 F 盘（本项目根 `F:\cb\nanoquant`）。构建命令一律带 `--manifest-path`。Windows 开发机联调用 `EXEC_TCP=127.0.0.1:9101`。

```rust
//! exec-core 协议 v1.0（JSON Lines，一行一请求/一响应，UTF-8，`\n` 结尾）。
//! op 集：hello | health | sign | metrics_ingest | metrics_query | metrics_reset；
//! order_open / order_close / protection_place 为二期预留，一期返回 reserved for phase 2。

use serde::{Deserialize, Serialize};

#[derive(Debug, Deserialize)]
pub struct Request {
    /// 请求 id，调用方生成，原样回传
    pub id: String,
    pub op: String,
    /// hello：调用方版本号
    #[serde(default)]
    pub version: String,
    /// sign：待签名的 query（不含 signature）
    #[serde(default)]
    pub query: String,
    /// metrics_ingest：批量样本
    #[serde(default)]
    pub samples: Vec<SampleIn>,
}

#[derive(Debug, Clone, Deserialize)]
pub struct SampleIn {
    /// total | plan | sign | http | wait | protect | persist
    pub segment: String,
    pub ms: f64,
    #[serde(default)]
    pub ts: i64,
}

#[derive(Debug, Serialize)]
pub struct Response {
    pub id: String,
    pub ok: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub algo: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub kernel_version: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub capabilities: Option<Vec<String>>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub metrics_capacity: Option<usize>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub uptime_ms: Option<u64>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub sessions: Option<u64>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub signature: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub query: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub accepted: Option<u64>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub dropped: Option<u64>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub segments: Option<serde_json::Value>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub error: Option<String>,
}

impl Response {
    pub fn ok(id: &str) -> Self {
        Self {
            id: id.to_string(), ok: true, algo: None, kernel_version: None,
            capabilities: None, metrics_capacity: None, uptime_ms: None, sessions: None,
            signature: None, query: None, accepted: None, dropped: None,
            segments: None, error: None,
        }
    }

    pub fn err(id: &str, msg: impl Into<String>) -> Self {
        Self {
            id: id.to_string(), ok: false, algo: None, kernel_version: None,
            capabilities: None, metrics_capacity: None, uptime_ms: None, sessions: None,
            signature: None, query: None, accepted: None, dropped: None,
            segments: None, error: Some(msg.into()),
        }
    }
}
```

```rust
//! 七段延迟指标：每段一个环形缓冲（满容量覆盖最旧），p50/p95/p99/max/last。
//! 索引法分位数与主服务 system.rs latency_view 同口径，无样本返回 null。

use crate::model::SampleIn;
use serde_json::{json, Value};
use std::sync::Mutex;

pub const SEGMENTS: [&str; 7] =
    ["total", "plan", "sign", "http", "wait", "protect", "persist"];

fn round2(v: f64) -> f64 {
    (v * 100.0).round() / 100.0
}

struct Ring {
    buf: Vec<f64>,
    cap: usize,
    next: usize,
    last: Option<f64>,
}

impl Ring {
    fn new(cap: usize) -> Self {
        Self { buf: Vec::new(), cap: cap.max(1), next: 0, last: None }
    }

    fn push(&mut self, ms: f64) {
        self.last = Some(ms);
        if self.buf.len() < self.cap {
            self.buf.push(ms);
        } else {
            self.buf[self.next] = ms;
            self.next = (self.next + 1) % self.cap;
        }
    }

    fn sorted(&self) -> Vec<f64> {
        let mut v = self.buf.clone();
        v.sort_by(f64::total_cmp);
        v
    }

    fn clear(&mut self) {
        self.buf.clear();
        self.next = 0;
        self.last = None;
    }
}

fn percentile(ordered: &[f64], q: f64) -> Option<f64> {
    if ordered.is_empty() {
        return None;
    }
    Some(ordered[((ordered.len() as f64 * q) as usize).min(ordered.len() - 1)])
}

pub struct MetricsHub {
    rings: Mutex<Vec<Ring>>,
    rejected: Mutex<u64>,
}

impl MetricsHub {
    pub fn new(capacity: usize) -> Self {
        Self {
            rings: Mutex::new((0..SEGMENTS.len()).map(|_| Ring::new(capacity)).collect()),
            rejected: Mutex::new(0),
        }
    }

    fn index_of(segment: &str) -> Option<usize> {
        SEGMENTS.iter().position(|s| *s == segment)
    }

    /// 批量写入：未知 segment 拒绝该条并计数，返回 (accepted, dropped)。
    pub fn ingest_batch(&self, samples: &[SampleIn]) -> (u64, u64) {
        let mut accepted = 0u64;
        let mut dropped = 0u64;
        if let Ok(mut rings) = self.rings.lock() {
            for s in samples {
                match Self::index_of(&s.segment) {
                    Some(i) => {
                        rings[i].push(s.ms);
                        accepted += 1;
                    }
                    None => dropped += 1,
                }
            }
        }
        if dropped > 0 {
            if let Ok(mut r) = self.rejected.lock() {
                *r += dropped;
            }
        }
        (accepted, dropped)
    }

    pub fn total_rejected(&self) -> u64 {
        *self.rejected.lock().unwrap_or(&0)
    }

    /// 七段视图：每段 {count,p50,p95,p99,max,last}，无样本的字段为 null。
    pub fn view(&self) -> Value {
        let rings = self.rings.lock().unwrap_or_else(|e| e.into_inner());
        let mut out = serde_json::Map::new();
        for (i, name) in SEGMENTS.iter().enumerate() {
            let ordered = rings[i].sorted();
            let p = |q: f64| percentile(&ordered, q).map(round2).map(Value::from).unwrap_or(Value::Null);
            out.insert(
                name.to_string(),
                json!({
                    "count": ordered.len(),
                    "p50": p(0.50),
                    "p95": p(0.95),
                    "p99": p(0.99),
                    "max": ordered.last().copied().map(round2).map(Value::from).unwrap_or(Value::Null),
                    "last": rings[i].last.map(round2).map(Value::from).unwrap_or(Value::Null),
                }),
            );
        }
        Value::Object(out)
    }

    pub fn reset(&self) {
        if let Ok(mut rings) = self.rings.lock() {
            for r in rings.iter_mut() {
                r.clear();
            }
        }
    }
}
```

注意：`Mutex::lock` 返回 Result，`view` 里用 `unwrap_or_else(|e| e.into_inner())`（poison 容错）；`total_rejected` 同理改为 `*self.rejected.lock().unwrap_or(&0)`——若编译器拒绝临时值引用，改为 `self.rejected.lock().map(|v| *v).unwrap_or(0)`。

```rust
//! NanoQuant 执行内核 exec-core v1.0（默认组件，非可选）。
//!
//! 职责：签名校验（sign）+ 七段延迟指标聚合（metrics_*）+ 长连接服务端。
//! 二期预留 order_open / order_close / protection_place（本期收到即报 reserved）。
//!
//! 运行（Linux，UDS）：EXEC_SECRET=... EXEC_SOCKET=/run/nanoquant/exec.sock ./exec-core
//! 运行（Windows 联调）：EXEC_SECRET=... EXEC_TCP=127.0.0.1:9101 ./exec-core
//! 协议见 docs/EXEC_PROTOCOL.md（v1.0）。

mod metrics;
mod model;
mod sign;

use std::path::PathBuf;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::Arc;
use std::time::Instant;

use tokio::io::{AsyncBufReadExt, AsyncRead, AsyncWrite, AsyncWriteExt, BufReader};
use tokio::net::TcpListener;
#[cfg(unix)]
use tokio::net::UnixListener;

use metrics::MetricsHub;
use model::{Request, Response};
use sign::Signer;

/// 连接空闲超时：主服务心跳 5s 一帧 health，30s 无帧视为死连接。
const IDLE_TIMEOUT_SECS: u64 = 30;

struct Sessions(AtomicU64);

impl Sessions {
    fn new() -> Self {
        Self(AtomicU64::new(0))
    }
    fn inc(&self) {
        self.0.fetch_add(1, Ordering::Relaxed);
    }
    fn dec(&self) {
        self.0.fetch_sub(1, Ordering::Relaxed);
    }
    fn get(&self) -> u64 {
        self.0.load(Ordering::Relaxed)
    }
}

struct Config {
    socket: PathBuf,
    secret: String,
    tcp: Option<String>,
    metrics_capacity: usize,
}

impl Config {
    /// 缺 EXEC_SECRET 返回 None（退出码 78 = EX_CONFIG，防 systemd 无限重启），沿用 exec-service 约定。
    fn from_env() -> Option<Self> {
        let secret = std::env::var("EXEC_SECRET").unwrap_or_default();
        if secret.trim().is_empty() {
            return None;
        }
        Some(Self {
            socket: std::env::var("EXEC_SOCKET")
                .unwrap_or_else(|_| "/run/nanoquant/exec.sock".into())
                .into(),
            secret,
            tcp: std::env::var("EXEC_TCP").ok().filter(|s| !s.trim().is_empty()),
            metrics_capacity: std::env::var("EXEC_METRICS_CAPACITY")
                .ok()
                .and_then(|v| v.trim().parse().ok())
                .filter(|v| *v > 0)
                .unwrap_or(2000),
        })
    }
}

async fn handle<S>(
    stream: S,
    signer: Arc<Signer>,
    hub: Arc<MetricsHub>,
    sessions: Arc<Sessions>,
    started: Instant,
) where
    S: AsyncRead + AsyncWrite + Unpin + Send,
{
    sessions.inc();
    let (read_half, mut write_half) = tokio::io::split(stream);
    let mut lines = BufReader::new(read_half).lines();
    let idle = std::time::Duration::from_secs(IDLE_TIMEOUT_SECS);
    while let Ok(Some(line)) = tokio::time::timeout(idle, lines.next_line()).await.flatten() {
        let line = line.trim().to_string();
        if line.is_empty() {
            continue;
        }
        let resp = match serde_json::from_str::<Request>(&line) {
            Ok(req) => dispatch(req, &signer, &hub, &sessions, started).await,
            Err(exc) => Response::err("unknown", format!("bad json: {exc}")),
        };
        let mut payload = serde_json::to_string(&resp).unwrap_or_default();
        payload.push('\n');
        if write_half.write_all(payload.as_bytes()).await.is_err() {
            break;
        }
        let _ = write_half.flush().await;
    }
    sessions.dec();
}

async fn dispatch(
    req: Request,
    signer: &Signer,
    hub: &MetricsHub,
    sessions: &Sessions,
    started: Instant,
) -> Response {
    match req.op.as_str() {
        "hello" => {
            let mut resp = Response::ok(&req.id);
            resp.kernel_version = Some(env!("CARGO_PKG_VERSION").to_string());
            resp.capabilities = Some(vec![
                "health".into(),
                "sign".into(),
                "metrics_ingest".into(),
                "metrics_query".into(),
                "metrics_reset".into(),
            ]);
            resp.metrics_capacity = Some(hub.capacity());
            resp
        }
        "health" => {
            let mut resp = Response::ok(&req.id);
            resp.algo = Some(signer.algo().to_string());
            resp.uptime_ms = Some(started.elapsed().as_millis() as u64);
            resp.sessions = Some(sessions.get());
            resp
        }
        "sign" => {
            if req.query.trim().is_empty() {
                return Response::err(&req.id, "empty query");
            }
            let mut resp = Response::ok(&req.id);
            resp.signature = Some(signer.sign(&req.query));
            resp.algo = Some(signer.algo().to_string());
            resp.query = Some(req.query);
            resp
        }
        "metrics_ingest" => {
            let (accepted, dropped) = hub.ingest_batch(&req.samples);
            let mut resp = Response::ok(&req.id);
            resp.accepted = Some(accepted);
            resp.dropped = Some(dropped);
            resp
        }
        "metrics_query" => {
            let mut resp = Response::ok(&req.id);
            resp.segments = Some(hub.view());
            resp
        }
        "metrics_reset" => {
            hub.reset();
            Response::ok(&req.id)
        }
        "order_open" | "order_close" | "protection_place" => {
            Response::err(&req.id, "reserved for phase 2")
        }
        other => Response::err(&req.id, format!("unknown op: {other}")),
    }
}

#[tokio::main]
async fn main() -> std::io::Result<()> {
    let Some(cfg) = Config::from_env() else {
        eprintln!(
            "exec-core: EXEC_SECRET 未配置，服务不启动。\n\
             请先填好交易所 API 凭证，再执行：sudo bash scripts/setup_core.sh --from-settings"
        );
        std::process::exit(78);
    };
    let signer = Arc::new(Signer::detect(&cfg.secret));
    let hub = Arc::new(MetricsHub::new(cfg.metrics_capacity));
    let sessions = Arc::new(Sessions::new());
    let started = Instant::now();
    eprintln!(
        "exec-core v{} starting (algo={}, metrics_capacity={})",

        signer.algo(),
        cfg.metrics_capacity

    if let Some(addr) = cfg.tcp.as_deref() {

            loop {
                match listener.accept().await {
                    Ok((stream, _)) => {
                        let (s, h, ss) = (s.clone(), h.clone(), ss.clone());
                        tokio::spawn(async move { handle(stream, s, h, ss, started).await });
                    }
                    Err(exc) => eprintln!("tcp accept failed: {exc}"),

            let socket = cfg.socket.clone();
            async move {
                let _ = tokio::signal::ctrl_c().await;
                let _ = std::fs::remove_file(socket);
                std::process::exit(0);
            }
        });
        loop {
            match listener.accept().await {
                Ok((stream, _)) => {
                    let (s, h, ss) = (signer.clone(), hub.clone(), sessions.clone());

                }
                Err(exc) => eprintln!("uds accept failed: {exc}"),

            return Err(std::io::Error::new(
                std::io::ErrorKind::InvalidInput,
                "Windows 无 UDS 支持：请设置 EXEC_TCP=127.0.0.1:9101",
            ));
        }
        loop {
            tokio::time::sleep(std::time::Duration::from_secs(3600)).await;
        }
    }
}
```

```rust
//! 统一替换此前三份 JSON Lines 客户端（探活 / verify / mock）。
//! 上报队列有界 8192，满则丢弃 + 计数，绝不阻塞下单路径。

use serde_json::{json, Value};
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::{Arc, Mutex, RwLock};
use std::time::{Duration, Instant};
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader, BufWriter};
use tokio::sync::mpsc;

pub const SEGMENTS: [&str; 7] =
    ["total", "plan", "sign", "http", "wait", "protect", "persist"];
const QUEUE_BOUND: usize = 8192;
const BATCH_MAX: usize = 64;
const BATCH_FLUSH: Duration = Duration::from_millis(200);
const HEARTBEAT: Duration = Duration::from_secs(5);
const RECONNECT_BASE: Duration = Duration::from_millis(250);
const RECONNECT_CAP: Duration = Duration::from_secs(8);

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum ConnState {
    Connected,
    Reconnecting,
    Disconnected,
}

#[derive(Clone)]
pub struct Sample {
    pub segment: &'static str,
    pub ms: f64,
}

struct Conn {
    reader: Mutex<BufReader<tokio::net::tcp::OwnedReadHalf>>,
    writer: Mutex<BufWriter<tokio::net::tcp::OwnedWriteHalf>>,
}

impl Conn {
    async fn connect_tcp(addr: &str) -> Result<Self, String> {
        let stream = tokio::net::TcpStream::connect(addr)
            .await
            .map_err(|e| format!("连接执行内核失败: {e}"))?;
        let (r, w) = stream.into_split();
        Ok(Self {
            reader: Mutex::new(BufReader::new(r)),
            writer: Mutex::new(BufWriter::new(w)),
        })
    }

    /// 一请求一响应（id 关联校验）。低频操作（探活/查询/上报批），串行足够。
    async fn roundtrip(&self, req: &Value) -> Result<Value, String> {
        let mut line = serde_json::to_string(req).map_err(|e| e.to_string())?;
        line.push('\n');
        {
            let mut w = self.writer.lock().map_err(|e| e.to_string())?;
            w.write_all(line.as_bytes()).await.map_err(|e| e.to_string())?;
            w.flush().await.map_err(|e| e.to_string())?;
        }
        let mut r = self.reader.lock().map_err(|e| e.to_string())?;
        let resp = tokio::time::timeout(Duration::from_millis(800), r.next_line())
            .await
            .map_err(|_| "执行内核响应超时".to_string())?
            .map_err(|e| e.to_string())?
            .ok_or("执行内核连接关闭")?;
        let value: Value = serde_json::from_str(&resp).map_err(|e| e.to_string())?;
        if value["id"] != req["id"] {
            return Err("执行内核响应 id 不匹配".into());
        }
        Ok(value)
    }
}

pub struct ExecClient {
    endpoint: String, // "tcp:127.0.0.1:9101" | "unix:/path"
    conn: RwLock<Option<Arc<Conn>>>,
    state: RwLock<ConnState>,
    last_error: Mutex<Option<String>>,
    tx: mpsc::Sender<Sample>,
    rx: Mutex<Option<mpsc::Receiver<Sample>>>,
    dropped: AtomicU64,
    pub connected_at: Mutex<Option<Instant>>,
}
```

API 与行为（实现时逐一落实，测试对端用真实 exec-core 二进制或内嵌 mock 监听，见步骤 2）：

- `ExecClient::new(endpoint: &str) -> Arc<Self>`：创建队列（`mpsc::channel(QUEUE_BOUND)`），不连接。
- `async fn handshake(&self) -> Result<Value, String>`：连接（按 endpoint 前缀 tcp/unix；unix 用 `tokio::net::UnixStream` + `#[cfg(unix)]`，Windows 下 unix 返回 Err）→ 发 `{"id":"hello-<ts>","op":"hello","version":"<主服务版本>"}` → 校验 `ok==true` 且 `kernel_version` 非空 → 存 conn、state=Connected、connected_at=now。失败时 state=Disconnected 并返回 Err。
- `fn spawn_maintainer(self: &Arc<Self>)`：tokio 任务循环——每 HEARTBEAT 发一次 health（探活成功刷新状态；失败置 Reconnecting 并进入重连循环：RECONNECT_BASE 起指数翻倍至 RECONNECT_CAP，每次重连成功重新 handshake）。
- `fn record(&self, segment: &'static str, ms: f64)`：`self.tx.try_send(Sample { segment, ms })`，`TrySendError::Full` 时 `dropped.fetch_add(1)`，**绝不 await、绝不阻塞**。
- `fn spawn_reporter(self: &Arc<Self>)`：tokio 任务——取走 rx，攒批（BATCH_MAX 条或 BATCH_FLUSH 超时）→ `metrics_ingest`（经当前 conn；conn 为 None 时丢弃本批并累计 dropped）。
- `async fn probe(&self) -> Result<(String, u128), String>`：health 一帧往返，返回 (algo, 往返 ms)。
- `async fn query_segments(&self) -> Result<Value, String>`：metrics_query，返回 `segments` 对象。
- `async fn reset_metrics(&self) -> Result<(), String>`：metrics_reset。
- `fn state(&self) -> ConnState`、`fn last_error(&self) -> Option<String>`、`fn dropped(&self) -> u64`。
